# UABasicS

### (ENGLISH)

**UABasicS** is a basic statistics R Shiny app that allows medicals to perform basic statistic analysis. This Shiny app provides the following tasks, without requiring knowledge of programming or statistics:

- **Upload** your own **database** (`.csv, .txt, .xls, .xlsx, .sav, .sas`) or example databases (https://higgi13425.github.io/medicaldata/ and https://github.com/lightbluetitan/meddatasets).
- **Preview the dataset**: Data table, summary and class of every variable.
- **Data transformation**: Transform variables to `factor` or `numeric` class, and logaritmic transformations.
- **Download new data** in .csv.
- **Univariate analysis:** Descriptive (summary tables and interactive plots).
- **Bivariate analysis:** Descriptive (summary tables and interactive plots) and statistical inference. **UABasicS** provides a descriptive table, with the p-value, of some variables respect a group variable, and the resultant table can be downloaded as a `Word` file.
- **General linear model**: Model for a `numeric` outcome and `numeric` or `categorical` covariates.
- **Logistic regression model**: Model for a `binary` outcome and `numeric` or `categorical` covariates.
- **UABasicS** provides **help files** about basic statistics too.


Developed by Marc Purgimon Serra as a part of their the Bachelor's Degree Final Project in Applied Statistics at Universitat Autònoma de Barcelona (UAB), 2026.

Available at https://purgimon.shinyapps.io/UABasicS/

### (CATALÀ)

**UABasicS** és una aplicació R Shiny d'anàlisi estadística bàsica dirigida a professionals sanitaris. L'aplicació permet realitzar les següents tasques, sense la necessitat de saber programació o estadística:

- **Carregar** la teva pròpia **base de dades** (`.csv, .txt, .xls, .xlsx, .sav, .sas`) o utilitzar bases de dades mèdiques d'exemple (https://higgi13425.github.io/medicaldata/ i https://github.com/lightbluetitan/meddatasets).
- **Previsualitzar les dades**: taula de dades, resum i classe de cada variable.
- **Transformacions de dades:** permet canviar la classe de cada variable a factor o numèrica, i també fer transformacions logarítmiques.
- També et permet **descarregar la base de dades** transformada, en format .csv.
- **Anàlisi univariant:** Anàlisi descriptiva, amb taules descriptives i gràfics interactius.
- **Anàlisi bivariant:** Anàlisi descriptiva, amb taules descriptives i gràfics interactius, i contrastos d'hipòtesis. També permet fer una taula descriptiva de diverses variables respecte una variable grup, que es pot descarregar com a fitxer `Word`.
- **Model lineal general**: Model per a una variable resposta `numèrica` amb covariants `numèriques` o `categòriques`.
- **Model de regressió logística:** Model per a una variable resposta `binària` amb covariants `numèriques` o `categòriques`.
- En cada cas disposes d'un fitxer d'ajuda.

Creada per Marc Purgimon Serra per al Treball de Final de Grau (TFG) d'Estadística Aplicada de la Universitat Autònoma de Barcelona (UAB), 2026.

Disponible a https://purgimon.shinyapps.io/UABasicS/
